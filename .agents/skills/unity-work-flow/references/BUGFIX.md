# Bug 修复

先把现象转成最小复现矩阵：Unity 版本、平台/设备、系统版本、场景、账号/存档、网络、画质、帧率与前后台状态。区分 Editor-only、设备-only、首次安装、升级安装和特定内容数据。

记录可观察的失败证据，再定位代码、序列化数据、资源导入、Package、原生 SDK 或平台配置的责任边界。优先添加能在最低层复现的回归测试；真机问题至少保留设备日志、Profiler/崩溃符号或操作步骤。

只修复根因和必要防护。不得用删除 `.meta`、清空 Library 后不解释、批量 reserialize、升级 Unity/Package 或吞掉异常来掩盖问题。无法自动化的回归风险进入需求卡 AC 和人工验证清单。
