# 本地化与玩家文本

沿用项目既有方案；新项目优先使用 Unity Localization Package。玩家可见文本不得散落在 C#、Prefab、Scene、Shader 或原生桥接代码中，调试日志和开发者诊断除外。

键使用可扩展点分语义，例如 `store.purchase.error.network`、`battle.result.victory.title`；层级按实际场景伸缩，不用最终中文作为键。文本变量使用命名参数，数量、性别、日期、货币和复数由本地化系统处理，不拼接句子。

变更时同步检查：fallback、缺键行为、字体/字形覆盖、动态字体与 Atlas、RTL（若支持）、截断/自动换行、安全区、触控区域、语音/字幕和原生 iOS 权限文案。伪本地化或至少一种长文本语言用于布局验证。

App Store 元数据不是运行时本地化资源；只有发布资料任务才处理，并单独保存市场、语言和版本对应关系。
